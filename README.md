# Automation Exercise Sandbox

A personal QA automation project built for learning.

## Tech Stack

* Python
* Pytest
* Playwright
* Requests
* GitHub Actions
* Git

## What I Practiced

* UI automation with Playwright
* API testing
* Page Object Model (POM)
* End-to-end testing
* Test assertions
* Handling flaky tests (retries, tracing)
* CI with GitHub Actions

## Tests

* Automation Exercise UI tests (search, cart, checkout, categories, brands)
* Automation Exercise API tests (products, brands, search, login, account creation)

## Running Tests

```
pip install -r requirements.txt
playwright install
pytest
```
